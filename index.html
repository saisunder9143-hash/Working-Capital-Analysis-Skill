Working capital analysis assistant

Enter revenue, cost of goods sold, current assets and current liabilities. The app calculates liquidity ratios, receivable, inventory and payable days, the cash conversion cycle, cash effects and data checks in code, so the numbers are exact. Claude then writes the analysis using the rules in a written Skill (SKILL.md).
